# Daniel Moya - Software Developer Portfolio

Portfolio bilingüe (ES/EN) con Next.js 14, pensado para GitHub Pages.

## Perfil

- Software Developer en **CITRI&CO** (junio 2025 – actualidad): ERP, SQL y Power Automate
- Backend Junior en **Factorial GmbH** (2024 – abril 2025): Drupal 10, IA y open source
- Grado en Ingeniería Informática (Universidad de Extremadura, 2020–2024)

## Stack del sitio

- Next.js 14 (export estático), React 18, TypeScript, Tailwind CSS
- i18next, Framer Motion, React Icons

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3001/Portfolio](http://localhost:3001/Portfolio/).

Los textos viven en `src/i18n/locales/`. Los CVs están en `public/cv/`.

## GitHub Pages

El sitio se publica con GitHub Actions en [https://danielmoyamdz.github.io/Portfolio/](https://danielmoyamdz.github.io/Portfolio/).

En el plan gratuito de GitHub, **el repositorio tiene que ser público**: Pages no sirve sitios de repos privados. En el repo: Settings → Pages → Source = **GitHub Actions**.
